# Bibliothèque PDF

**Statut : projet historique documenté — source originale non disponible.**

## Contexte
Projet de moteur de bibliothèque et recherche de documents.

## Objectif
Indexation et consultation de ressources.

## Code et démonstration
Ce dossier contient uniquement une fiche descriptive. Le code original, les captures et les résultats ne sont pas disponibles pour vérification. Il ne faut pas considérer ce README comme une preuve de fonctionnement ou un dépôt complet.

## Étapes pour compléter le projet
1. Retrouver les sources originales et confirmer les droits de publication.
2. Nettoyer les identifiants, secrets et données privées.
3. Ajouter une procédure d'installation reproductible.
4. Ajouter des captures authentiques et des tests.
5. Rédiger l'architecture et les limites.

## Précautions
