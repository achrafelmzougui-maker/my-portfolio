# Arabic Learning Game — browser mini-demo

A **new HTML/JS reconstruction** inspired by the earlier JavaFX + SQL educational game project. The original Java/Scene Builder/SQL source has **not** been recovered. This mini-demo is independent and uses no database.

Open `index.html` in a browser or visit GitHub Pages at `/my-portfolio/arabic-learning-game/`. Four elementary vocabulary questions; answers and scoring run locally, with no tracking or account.
