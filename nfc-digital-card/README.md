# NFC Digital Developer Card — static web demo

A new responsive, **public profile landing-page starter** suitable as the URL target of an NFC card or QR code. It does not write NFC tags and is not the recovered source of the original personal NFC project.

Edit the display name, links and contact information in `index.html` before publishing personal details. No analytics, no external libraries. Open locally or on GitHub Pages at `/my-portfolio/nfc-digital-card/`.
